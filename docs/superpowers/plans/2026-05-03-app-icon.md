# ABCNote App Icon Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a formal ABCNote application icon to the Windows executable, window, and deploy package.

**Architecture:** Store deterministic icon source assets under `assets/icon`. Generate a multi-resolution Windows `.ico`, reference it from a Windows resource script, include that resource in the `ABCNote` target, and set the Qt window icon at startup.

**Tech Stack:** Qt 6, CMake, Windows RC resources, PowerShell/.NET drawing for deterministic raster generation.

---

- Create: `assets/icon/ABCNote.ico`

### Task 2: Wire Windows and Qt Icons

**Files:**
- Create: `src/app.rc`
- Modify: `CMakeLists.txt`

- [ ] If using Qt resource embedding for runtime window icon, add the icon file to the QML/resource module.
