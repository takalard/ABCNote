# ABCNote 数据目录设置设计

## 目标

在应用右上角新增设置入口，让用户查看并更改笔记数据保存目录。默认数据目录改为应用可执行文件同级目录下的 `data` 文件夹。用户选择新目录后，应用自动迁移当前目录中的已有笔记数据，迁移成功后切换到新目录并刷新界面。

## 用户体验

顶部工具栏右侧保留当前自动保存状态，并新增一个设置按钮。点击设置按钮后显示当前数据目录和“更改目录”操作。用户点击“更改目录”后打开系统目录选择器。

选择新目录后，应用先保存当前未保存笔记，再把旧目录中的文件复制到新目录。迁移成功后，状态栏提示已切换数据目录，左侧日期导航和右侧笔记流使用新目录重新加载。旧目录保留不删除，作为用户数据备份。

如果目标目录已有同名文件，迁移时保留目标文件，不覆盖。切换仍然可以完成，但状态栏提示部分文件已存在。若复制过程中出现目录创建或文件复制失败，应用保持使用旧目录，并提示迁移失败。

## 架构

新增 `AppSettings` QObject，负责：

- 计算默认数据目录：`QCoreApplication::applicationDirPath()/data`。
- 通过 `QSettings` 持久化用户选择的数据目录。
- 向 QML 暴露当前数据目录、选择目录动作和切换结果状态。
- 协调切换流程：保存当前编辑、迁移文件、更新存储路径、刷新模型。

`NoteStorage` 增加切换根目录能力和目录复制辅助能力。存储仍然负责 `YYYY/MM/YYYY-MM-DD.json` 的笔记文件结构，不负责 UI。

`NoteController` 增加重新加载当前数据目录的方法：切换目录前调用 `flush()`，切换目录后重新初始化当前日期附近的笔记流并刷新导航。

`main.cpp` 改为先创建 `AppSettings`，由它决定数据根目录，再创建 `NoteStorage`。`AppSettings` 作为 QML context property 暴露给 `Main.qml`。

## 数据流

启动时：

1. `AppSettings` 读取 `QSettings` 中的 `dataRoot`。
2. 如果没有用户配置，使用应用同级 `data` 目录。
3. `NoteStorage` 用该路径初始化。
4. 控制器按当前日期启动。

切换目录时：

1. QML 调用 `appSettings.chooseDataDirectory()`。
2. `AppSettings` 打开系统目录选择器。
3. 用户确认后，控制器 `flush()` 当前修改。
4. `AppSettings` 复制旧目录内容到新目录。
5. 成功后 `NoteStorage` 切换根目录，`QSettings` 记录新路径。
6. 控制器重新加载当前日期窗口，导航刷新。

## 错误处理

用户取消目录选择时不改变状态。新目录与当前目录相同时不迁移，只提示目录未改变。

迁移失败时，应用保持旧目录和旧数据视图，状态栏提示失败。目标目录已有同名文件时不覆盖，继续迁移其他文件，并在成功切换后提示部分文件已存在。

## 测试

新增非 UI 单元测试覆盖：

- 默认数据目录位于应用目录下的 `data`。
- 设置目录会持久化到 `QSettings`。
- 迁移会复制旧数据树到新目录。
- 迁移遇到同名文件时不覆盖目标文件。
- 迁移失败时不会切换 `NoteStorage` 根目录。

QML 变化以构建验证为主：确认 `Main.qml` 能编译加载，设置按钮绑定到 `AppSettings` 的属性和方法。
