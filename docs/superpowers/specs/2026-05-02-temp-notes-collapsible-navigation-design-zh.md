# 临时笔记与可折叠导航设计

日期：2026-05-02

## 目标

调整 ABCNote：空白日期只作为内存中的临时笔记存在；左侧年/月导航支持展开和收缩。

## 行为

打开软件时，右侧仍然显示今天的笔记。但是如果正文为空，不创建 JSON 文件，也不把该日期作为真实记录显示到左侧导航。

向前或向后滚动加载日期时，也只创建内存临时笔记。只有当正文去掉首尾空白后不为空，该日期才会真正持久化。

如果已有持久化笔记被清空正文，它对应的 JSON 文件会被删除。该日期仍可在右侧作为临时页面继续显示，但会从左侧导航中消失。

左侧导航只显示已经持久化且有内容的笔记。年和月行可以展开或收缩。日行保持可点击，并跳转到右侧对应日期。

## 实现说明

`NoteStorage` 会增加非创建式加载、存在性检查、删除支持，以及按内容决定保存或删除的逻辑。

`NoteModel` 加载临时笔记时不写文件。编辑内容先保存在内存中，直到控制器 flush。

`NoteController` 只持久化非空正文。空的待保存笔记会删除已存在文件。

`NavigationModel` 会保存年/月展开状态。它会暴露 `expanded`、`expandable` 角色，并提供 `toggleExpanded(row)` 供 QML 调用。

## 验证

测试需要证明：

- 加载缺失笔记不会创建文件。
- 保存空笔记会删除文件或保持文件不存在。
- 控制器启动不会创建今天的文件。
- 临时笔记编辑为非空后，flush 会创建文件。
- 已持久化笔记清空后，flush 会删除文件。
- 导航中的年/月行可以收缩和展开。
